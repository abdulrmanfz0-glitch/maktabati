# web

The Maktabati web application: reader, study tools, library, quote cards,
ambient sounds and the AI companion. The source is split between
`src/legacy/app.js` (the current application) and the ingest bridge in
`src/ingest/`.

This is not a PWA yet: there is no web app manifest and no service worker.
See the repository root `README.md` for setup and limitations.
